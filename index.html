🔑 Token necə yaradılır (addım-addım)

      
    
        
  1. GitHub-da sağ yuxarıdaki profil şəklinə bas → Settings.
    2. 
        
  2. Sol menyuda ən aşağıda Developer settings → Personal access tokens → Fine-grained tokens.
    3. 
        
  3. Generate new token düyməsinə bas.
    4. 
        
  4. Token name: ai-engineer-tracker yaz.
    5. 
        
  5. Expiration: 90 gün (və ya 1 il) seç. Vaxtı bitəndə yenisini yaradacaqsan.
    6. 
        
  6. Repository access: Only select repositories → yalnız ai-engineer-tracker seç.
    7. 
        
  7. Permissions → Repository permissions → Contents: Read and write seç. Başqa heç bir icazə vermə.
    8. 
        
  8. Generate token düyməsinə bas və github_pat_... ilə başlayan açarı kopyala.
    9. 
        
  9. Açarı yuxarıdaki sahəyə yapışdır və Tokeni yadda saxla-ya bas. Token yalnız bu brauzerin localStorage-ində saxlanılır, heç vaxt repoya commit edilmir.
    10. 
        
  10. Sonra Bağlantını yoxla düyməsinə bas — "Bağlantı uğurludur" mesajını görməlisən.
    11. 
      

      
⚠️ Tokeni ekran şəklində paylaşma, koda yazma, repoya commit etmə. Şübhələnsən dərhal GitHub-da Revoke et və yenisini yarat.
